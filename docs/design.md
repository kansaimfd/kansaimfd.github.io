# デザイン

色・フォント・スタイルの書き方。作業の入口は [CLAUDE.md](../CLAUDE.md)（索引）。

- **カラー**: ネイビー（`#1B2E4B`）＋ゴールド（`#B8962E`）＋クリーム背景（`#F8F6F0`）
- **府県アクセント**: 一覧のカードと絞り込みのピルは府県ごとに色を変える
  （大阪=ネイビー／京都=茶／兵庫=緑／奈良=ゴールド／滋賀=青／和歌山=臙脂）。
  **色の定義は `styles/tokens.css` の `[data-pref='京都府']` だけに置く。**
  要素に `data-pref={都道府県}` を付ければ `--pref-accent` / `--pref-tint` / `--pref-chip` が切り替わる。
  JS 側に色表を持たせない（カードとピルで別々に持つと必ず食い違う）
- **地図**: 地は `tokens.css` の `--map-*` で塗る（クリーム寄りで彩度を落とし、ピンより前に出さない）。
  WebGL で描くので CSS変数を直接は使えず、`createMap.ts` が描画前に値を読んで `buildMapStyle()` に渡す。
  **ピンは府県アクセント色のしずく型**で、`data-pref` を付けた DOM 要素なので色は CSS から来る。
  面（アクセント）の明暗はテーマで入れ替わるので、**その上に載る芯と選択中の輪も
  テーマごとに持つ**（`--map-pin-core` / `--map-pin-ring`。芯は6府県すべての面の上で 3:1 以上）。
  拡大・縮小と出典は maplibre が白い面と黒いアイコンを自前の CSS に持っているため、
  面はトークンで上書きし、**色を焼き込んだ SVG のアイコンは明暗を反転させる**
  （反転量は `--map-ctrl-invert`）。
  maplibre-gl は gzip 約420KB あるので、**地図のコンポーネントは一覧・詳細とも遅延読み込み**する
  （v6 はバンドラを通すと共有部分が本体とワーカーに二重に入る。v5 なら約280KB だが既知の脆弱性がある）
- **フォント**: 見出しに Noto Serif JP（クラシカル感）、本文に Noto Sans JP
- **テーマ**: クラシック音楽・オーケストラ・親しみやすい・モダン
- **ダークモード**: OS の設定に従う（`prefers-color-scheme`）。切り替えのスイッチは置かない。
  **`tokens.css` で値を差し替えるだけ**で、役割の名前（`--color-cream` は地、
  `--color-surface` はカード・表の面）はライトと共通。他の CSS は変数しか見ていないので触らない。
  `--color-navy-700` は**文字**としてのネイビー（27か所）でダークでは明るい側へ動き、
  ヘッダー・主ボタンの**地**は `--color-navy-surface` が持つ（暗いまま）。
  府県アクセントもダークの表を別に持つ（淡い tint をそのまま持ち込むと暗い画面に明るい板が残る）。
  **コントラストは両テーマとも `contrast.test.ts` が見ている**（文字 4.5:1、罫と大きな文字 3:1、
  府県アクセントは自分の tint と面の上で 4.5:1、地図のピンは地と芯が 3:1）。
  **`select` の地を `transparent` にしない**——開いたときの選択肢の一覧はブラウザが
  select の地の色から作るので、透明だと白い板に落ちて明るい文字が読めなくなる
  （`color-scheme`（base.css）だけでは足りない）

## スタイルの書き方

**スタイルは `src/styles/` の CSS ファイルにしか書かない。**
Tailwind のユーティリティクラスも、JSX の `style={{}}` も使わない。
以前はコンサートホール一覧だけが 62 個のインライン `style` で書かれていて、
色・文字サイズ・角丸が他のページと揃わず、そのページだけ浮いて見えていた。

- **色・文字サイズ・角丸・字送りは `tokens.css` の変数から取る。** 生の16進数をコンポーネントに書かない
- ファイルは読み込み順に意味がある（`index.css` を参照）。
  `tokens`（値）→ `base`（要素の既定値）→ `layout`（骨格）→ `components`（部品）→ `pages`（ページ固有）。
  後ろほど具体的なので、詳細度を上げずに上書きできる
- クラス名は BEM 風（`block__element--modifier`）
- **折り返しは CSS のメディアクエリで行う。** 画面幅を JS で測って表示を切り替えない
  （`resize` のたびに数百件のカードが再描画される）。区切りは 640px と 1024px の2か所
- **一覧のカードは `FacilityCard` ひとつ。** コンサートホールと練習場で共通で、
  違うのは数値の欄（`stats`）と設備バッジ（`equip`）だけ。一覧ごとにカードを書き分けない。
  検索窓（`SearchBox`）と並び替えの切り替え規則（`toggle.ts` の `nextSort`）も
  同じ理由で共通にしてある
- **詳細ページは一覧のカードと同じ部品で組む。** 府県帯（`PrefBand`）・最寄駅（`StationList`）・
  数値（`Stat`）・設備バッジ（`EquipBadge`）を共有し、見出しは `DetailHead`、部屋は `RoomCard`
  （両詳細ページで共通）。以前は詳細ページだけが素の表で、一覧から来ると別サイトのように見えた。
  部屋の設備はバッジではなく〇／×／—で全部並べる（バッジは「あり」しか出ず、「なし」と「未調査」が消える）
- **色は `tokens.css` で決まり、文字色はクリーム地・白地の両方で
  コントラスト比 4.5:1 以上**（`src/styles/contrast.test.ts` が確かめる）。
  薄い色は作った画面では上品に見えるので、目視では落ちない

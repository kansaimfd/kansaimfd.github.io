# 要求仕様

## 非機能要件

- **レスポンシブデザイン** — スマートフォンでの閲覧に対応する
- **デプロイ先** — GitHub Pages（静的ホスティング、バックエンドなし）
- **デザイン方針** — クラシック音楽・オーケストラ・親しみやすい・モダン。ネイビー＋ゴールドの配色、見出しにセリフ体フォント（Noto Serif JP）を使用

---

## ページ構成

### このサイトについて

利用規約、免責事項、GitHubのプロジェクトページへのリンク、プライバシーポリシーを掲載します。

---

### コンサートホール一覧

`concerthall.yaml` の施設を一覧で表示します。URL: `/concert`

**表示形式（切り替え可能）:**
- リスト — カード形式でリッチな見た目
- 表 — テーブル形式で一覧性を重視
- 地図 — 施設の経緯度をピン表示（MapLibre GL JS + OpenStreetMap ベクトルタイル）
  - ピンをクリックするとポップアップを表示（施設名、住所、最寄駅情報、詳細ページへのリンク）

**フリーワード検索:** 施設名・住所などで絞り込み

**フィルタリング条件:**
- 都道府県
- 市区町村
- 最寄駅路線
- 最寄駅徒歩（〜分以内）
- 客席数（範囲指定）
- ピアノ有無
- パイプオルガン
- 譜面台貸出
- 親子室
- 駐車場あり（台数 > 0）

**並び替え:** 施設名、都道府県、客席数、最寄駅徒歩 など

---

**備考:** 同一施設に複数ホール（部屋名で区別）がある場合、一覧では別エントリとして表示する。

---

### コンサートホール詳細

コンサートホール一覧の各施設リンクをクリックすると開くページ。URL: `/concert/:id`

**表示内容:**
- YAMLの全フィールド
- 施設位置の地図表示（ピン1件）
- 公式サイト・申込URL・料金URLへのリンク

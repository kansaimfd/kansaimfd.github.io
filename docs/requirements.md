# 要求仕様

**この文書は「何を作るか」を書く。** 作り方の判断基準・スキーマの詳細は
[CLAUDE.md](../CLAUDE.md) にあり、食い違ったときは**動いているコードと CLAUDE.md が正**。
ここには、実装済みのものと**まだ実装していないもの**を区別して書く。

## 非機能要件

- **レスポンシブデザイン** — スマートフォンでの閲覧に対応する。折り返しは CSS のみで行い、
  区切りは 640px と 1024px の2か所
- **デプロイ先** — GitHub Pages（静的ホスティング、バックエンドなし）。
  **現在は停止中**（→ CLAUDE.md「Deployment」）
- **デザイン方針** — クラシック音楽・オーケストラ・親しみやすい・モダン。
  ネイビー＋ゴールドの配色、見出しにセリフ体フォント（Noto Serif JP）を使用
- **一覧の状態はURLが持つ** — 絞り込み・並び替え・表示の切り替えはクエリに載せる。
  絞り込んだ結果をそのまま人に送れて、詳細ページから戻っても条件が残るため
- **未調査を「無い」として扱わない** — 条件に合わないのではなく調べていないだけの施設は、
  絞り込みから外したうえで**件数と項目名を画面に出す**

### コンサートホール一覧

`data/facilities/concerthall.yaml` の施設を一覧で表示します。URL: `/concert`（トップも同じ一覧）

**表示形式（切り替え可能）:**

- リスト — カード形式。**1施設1枚**（複数ホールの施設は、カードの中に
  ホールごとの数値を重ねる）
- 表 — テーブル形式で一覧性を重視。**1行 = 1ホール**
- 地図 — 施設の経緯度をピン表示（MapLibre GL JS + OpenStreetMap ベクトルタイル）。
  ピンは**施設ごとに1本**。押すとポップアップ（施設名、住所、最寄駅、詳細ページへのリンク）

**フリーワード検索:** 施設名・施設名かな・部屋名・住所・最寄駅名で絞り込み

**フィルタリング条件（実装済み）:**

- 都道府県
- 市区町村（選んだ都道府県の中から選ぶ）
- 最寄駅
- 最寄駅徒歩（〜分以内）
- 客席数（範囲指定）
- 舞台幅・舞台奥行（範囲指定）
- ピアノ有無 / パイプオルガン / 譜面台貸出 / 親子室 / 駐車場あり（台数 > 0）
- 貸館終了・閉館も表示（既定では隠す）

**画面に出していない条件:**

- ホール種別 — 「多目的」の語が平土間の多目的室を連想させ、反射板を持つ劇場型ホールと
  区別できないため外してある。データ・型・`filterHalls` の条件は残っている（→ CLAUDE.md）

**並び替え:** 施設名（五十音順）、都道府県、客席数、最寄駅徒歩。
**未調査は向きに関わらず末尾**に置く（→ `src/sort.ts`）

**絞り込み・並び替えはホール単位**で行い、カードに束ねるのは最後。
条件に合わないホールはカードに出ない。

### コンサートホール詳細

コンサートホール一覧の各施設リンクをクリックすると開くページ。URL: `/concert/:id`

**表示内容:**

- 見出し（施設名・住所・最寄駅・公式サイト / 申込 / 料金へのリンク）と施設全体の数値・設備
- 貸館の休止・終了、利用条件の案内
- 部屋ごとの数値と設備（**〇／×／— を全部並べる**。バッジだと「なし」と「未調査」が消える）
- 施設情報（TEL・開館時間・休館日・築年月・駐車場）
- 施設位置の地図表示（ピン1件）
- 出典の**最終確認日**（出典のURL・備考は画面に出さない。出典が無ければその旨を出す）

### 練習場一覧

`data/facilities/practice.yaml` の施設に加え、**コンサートホール施設の「ホールでない部屋」**
（練習室・リハーサル室・スタジオなど）を持つ施設も表示します。URL: `/practice`

**表示形式（切り替え可能）:** コンサートホール一覧と同じ（リスト・表・地図）

**フリーワード検索:** 施設名・施設名かな・住所・最寄駅名で絞り込み

**フィルタリング条件（実装済み）:**

- 都道府県
- 市区町村（選んだ都道府県の中から選ぶ）
- 最寄駅
- 定員（◯名以上。施設内で最も定員の多い部屋で判断する）
- 最寄駅徒歩（〜分以内）
- ピアノ有無 / 管楽器 / 打楽器 / チェンバロ
- 貸館終了・閉館も表示（既定では隠す）

**並び替え:** 施設名（五十音順）、都道府県、最寄駅徒歩

**用途の分類（オーケストラ用／アンサンブル用）は持たない。** 主観的なので、部屋の `定員` で絞る。

---

### 練習場詳細

練習場一覧の各施設リンクをクリックすると開くページ。URL: `/practice/:id`

**表示内容:** コンサートホール詳細と同じ組み立て（部屋の欄は定員・面積・楽器の可否）。

**ホール併設の練習室はコンサートホール側の詳細ページ（`/concert/:id`）へ行く。**
IDの名前空間がファイルごとに別なため、リンクは `practiceDetailPath()` で作る。

---

### 見つかりません

存在しないURL・存在しないIDで開いたときの案内。`404.html` は `noindex` で返す。

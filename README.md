# このサイトについて

関西の音楽練習場、コンサートホールの情報をまとめています。各種条件で検索することができます。

## コントリビューション

施設データの追加・修正にご協力いただける方は [コントリビューションガイドライン](./CONTRIBUTING.md) をご覧ください。

開発の手引き（コマンド・構成・スキーマ・配信）は [`docs/`](./docs/) にあります。

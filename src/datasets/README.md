# src/datasets

変換後JSONの読み込み口。**データセットごとにファイルを分けているのは、
バンドルを分割できるようにするため**。

1つのモジュールが複数のJSONをまとめて import すると、そのモジュールに触れた
時点で全データが同じチャンクに入る。入口のコンサートホール一覧しか見ない
利用者にも、練習場のデータや詳細ページ用のデータが配られてしまう。

ページからは必要なデータセットだけを import すること。

## 一覧と詳細でJSONを分けている

- `concerthalls.ts` / `practices.ts` — **一覧・地図用**。静的 import。
  一覧が読むフィールドだけに絞ってある（`transform.mjs` の
  `LIST_FACILITY_FIELDS` ほか）。TEL・休館日・料金URL・出典などは入っていない
- `facility.ts` — **詳細ページ用**。1施設1ファイルを動的 import で読む

詳細ページが全施設ぶんのJSONを静的 import していたころ、`/concert/10` を
直接開くと1施設を見るために gzip 171KB が届いていた。詳細ページの直リンクは
外部からの入口そのものなので、ここが一番重かった。今は施設1件あたり gzip 4KB。

`facility.ts` が返すPromiseは施設ごとに使い回している。**`use()` に渡す
Promiseは、同じ施設なら毎回同じものでなければならない**（描画のたびに新しい
Promiseを作ると、解決しても次の描画でまた別のPromiseを待つことになる）。
